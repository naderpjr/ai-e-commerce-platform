# 🛋️ E-commerce Platform

Modern full-stack furniture e-commerce platform built with **Next.js, Sanity, Clerk, Zustand & Tailwind**.

> ⚠️ AI assistant, and Stripe payment are currently **inactive**.  
Core store, CMS, authentication, and dashboard are fully functional.

---

## ✨ Overview

A production-style e-commerce web app designed for portfolio and real-world architecture practice.

Includes storefront, admin dashboard, CMS integration, authentication system, and persistent cart with modern UI.

Clean, scalable, and ready for future AI + payment integration.

---

## 🧩 Active Features

- Product listing & categories  
- Real-time data from Sanity CMS  
- Authentication system (Clerk)  
- Admin dashboard for products & orders  
- Persistent cart (Zustand)  
- Responsive modern UI  
- Production-ready structure  

---

## ⚠️ Inactive Modules

These parts exist but are not configured:

- AI assistant  
- Stripe payment & checkout  
- AI admin insights  

Project currently works as a **complete UI + CMS + Auth e-commerce platform**.
